# Seamless Connect

## Open Infrastructure for Domain Operations and Agent Bootstrapping

Seamless Connect is an open-source, cross-provider developer CLI for discrete, authorized domain operations and agent bootstrapping. It is maintained as a core Internet utility under nonprofit administration.

Early industry participation includes Name.com (Identity Digital), Cloudflare, and DigiCert.

## Participation and governance

Name.com (Identity Digital) is the founding sponsor. Cloudflare and DigiCert are founding contributors. Nonprofit administration is provided by the [Foundation for Agentic Networks (FAN)](https://www.agenticnet.org/). Technical participation is independent of sponsorship.

## Capability status

The initial focus is DNS configuration through Domain Connect. DNSSEC, Primary / Secondary DNS, Domain Registration, and Agent Bootstrapping describe planned or developing workflows; availability depends on the operation and participating provider integrations. Industry participation does not imply implemented integrations. See [Use Cases & Protocols](https://seamlessconnect.org/use-cases/) for the five intended use cases and protocol references.

This description is the canonical public messaging reference. It does not change the [project charter](https://github.com/seamless-connect/spec/blob/main/governance/CHARTER.md), technical specifications, or provider support status.
